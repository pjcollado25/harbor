# Harbor — irregular-income companion

**Design package status:** research-informed concept specification; primary user research has not yet been conducted. Harbor is a working name. The editable [Figma design file](https://www.figma.com/design/2bdYwU0SN4q6aBctNmoK2Q) is in Pj’s Company.

This package contains eight design and research documents. The runnable Flutter app is documented in the repository [README](../../README.md) and architecture notes. The local HTML prototype opens in a dark iPhone-style device frame on wider screens, includes a light/dark toggle, and uses glass styling on navigation and summary surfaces. The app now follows the latest direction: dark-first, black and blue palette, iPhone-sized layouts, a floating glass bottom bar, icon-only navigation, and Settings as a gear icon. The Figma design file retains earlier light-style frames. All sample data is fictional and the app does not connect to banks or payment rails.

## Important status

- External research is cited in Page 01. Findings are scoped to each source's geography, population, and method.
- There are **no findings validated with Harbor participants**. Interviews, usability sessions, and outcome measures remain planned work.
- The Figma presentation uses three pages: **01 — Research + strategy** (Sections 01–02), **02 — Structure + system** (Sections 03–05), and **03 — Screens + validation** (Sections 06–08). Section 06 is represented by 13 iPhone-framed screens; Section 07 by linked prototype flows and three recovery states; Section 08 by a usability-testing plan board.
- The Figma prototype links primary navigation, bill creation, bill detail, reminders, payment recording and Undo, plus the delayed-income scenario. It is a visual click-through; form state is simulated in the separate HTML prototype.
- The [local HTML prototype](../../prototype.html) demonstrates add-bill validation, reminders, payment entry and Undo, bill filters, activity, and an income-delay scenario with recovery. It is not connected to financial services and has not been user-tested.
